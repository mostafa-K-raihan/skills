# Notice

This repository contains an original Agent Skill for technical writing workflows.

The skill is inspired by broadly used technical writing practices, including reader-first organization, task-oriented documentation, clear examples, accessibility, actionable error messages, evidence-first prose, and concrete language. It was also informed by public technical writing education material, including Google's Technical Writing courses, and by the MIT-licensed `luoling8192/technical-writing` skill for Chinese technical prose review patterns.

It does not include or redistribute third-party course text, examples, exercises, diagrams, or other copyrighted content. Names of referenced resources are used only for attribution and context. All rights in referenced works remain with their respective owners.
